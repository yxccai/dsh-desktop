# DSH Desktop Custom Background

A managed presentation plugin that lets the user choose a local PNG, JPEG, WebP, or GIF background through an allowlisted native file picker. The image is copied into the DSH Desktop data directory and rendered with a readability overlay. An opacity control (10–100%) in the plugin center adjusts how strongly the image shows through; the readability overlay is always kept on top. Disabling or uninstalling removes the visual effect; clearing explicitly deletes the stored image.
